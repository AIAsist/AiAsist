# 🛵 Курьер: Сестрорецк

Аркадный симулятор курьера на **настоящей карте Сестрорецка**. Улицы, дома с адресами, кафе и магазины,
Разлив и Финский залив взяты из [OpenStreetMap](https://www.openstreetmap.org). Игра работает в браузере
на компьютере и на телефоне.

## Как играть

- **Движение:** WASD / стрелки. На телефоне или мышью: зажми палец и тяни, получается джойстик.
- **Заказы:** справа (на телефоне снизу) появляются заказы рядом. Нажми карточку или 1, 2, 3.
  - оранжевый круг: забрать заказ в кафе или магазине;
  - зелёный круг: отдать клиенту по адресу.
- **Навигатор:** синяя линия ведёт по улицам. Если цель за экраном, у края появляется стрелка. Внизу мини-карта.
- **Деньги:** за доставку платят по длине маршрута. Чем быстрее довёз, тем больше чаевые. Доставки вовремя подряд дают бонус серии 🔥.
  Опоздание срезает оплату и рейтинг.
- **Гараж (G):** пешком → велосипед → электросамокат → мопед. Быстрее транспорт — дальше и дороже заказы,
  но по траве и дворам техника едет хуже, чем пешеход.
- **Масштаб:** колесо мыши или щипок двумя пальцами.
- **V** включает 3D-вид (бета). **M** выключает звук. **R** возвращает на дорогу, если застрял. **H** открывает справку.

Прогресс (деньги, транспорт, рейтинг) сохраняется в браузере.

## Запуск у себя

Нужен [Node.js](https://nodejs.org) 20+ и интернет (для скачивания карты).

```bash
cd courier-game
npm install
npm run map     # скачать Сестрорецк из OpenStreetMap → public/data/sestroretsk.json
npm run dev     # открыть http://localhost:5173
```

`npm run map` берёт границы города из OSM (административная граница «Сестрорецк») и скачивает через
Overpass API дороги, здания, воду, зелень, кафе, магазины и адреса. Если основной сервер Overpass
не отвечает, скрипт сам пробует зеркала, в том числе российское `maps.mail.ru`. Город качается
квадратами примерно 3×3 км: один большой запрос бесплатные серверы обрывают. Каждый квадрат кэшируется
в `data-raw/`, поэтому повторный запуск продолжит с места сбоя. Чтобы обновить карту, запусти
`npm run map -- --refresh`.

Другие варианты:

- `npm run map -- --bbox=60.06,29.89,60.14,30.04`: свой прямоугольник (юг, запад, север, восток);
- `npm run map -- --input=export.json`: собрать из готового ответа Overpass, например сохранённого
  на [overpass-turbo.eu](https://overpass-turbo.eu) (запрос печатает `src/osm/overpass.ts`);
- `npm run map:test` и потом `?map=test-town` в адресе: вымышленный «Тестоград» для разработки без интернета.

Проверки: `npm test` (юнит-тесты) и `npm run typecheck`.

## Публикация на GitHub Pages

Workflow `.github/workflows/courier-game.yml` на каждый пуш делает следующее:
1. прогоняет тесты;
2. скачивает карту Сестрорецка (кэш на месяц, ручной запуск с галочкой «скачать заново»);
3. собирает сайт.

Пуш в `main` дополнительно публикует сайт.

Один раз нужно включить Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
После этого игра будет по адресу `https://<пользователь>.github.io/<репозиторий>/`.

## Как устроено

```
courier-game/
├── scripts/build-map.ts     скачивание из Overpass + конвертация (CLI)
├── src/osm/                 OSM → формат игры: дороги и граф, здания с высотой, вода,
│                            море из линии берега, зелень, точки выдачи и адреса
├── src/data/mapFormat.ts    компактный формат карты (метры, x — восток, y — север)
├── src/world/               правила игры БЕЗ графики: физика курьера, столкновения,
│                            маршруты (A*/Дейкстра), заказы, экономика, сохранения
├── src/render/              Three.js: слои карты, 3D-здания, курьер, маркеры, маршрут
└── src/ui/                  интерфейс: панель заказов, гараж, мини-карта, джойстик, звуки
```

### Задел на 3D

- Симуляция (`src/world`) не знает про графику: та же игра может работать с любым видом.
- Уже сейчас всё рисуется в **Three.js**. «2D» — это ортографическая камера строго сверху,
  а здания уже настоящие 3D-коробки с высотой из OSM (`height` / `building:levels`).
  Кнопка **3D** просто наклоняет камеру.
- Курьер — 3D-модель из примитивов. Её можно заменить на GLTF-модель без изменений в логике.

Следующие шаги к полноценному 3D:
- модели транспорта и курьера (GLTF);
- деревья (instancing) в лесах и парках;
- крыши по `roof:shape`;
- камера «из-за спины» с поворотом;
- день и ночь, погода.
