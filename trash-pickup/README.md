# 🗑️ Вынос мусора от двери — прототип

Сервис: клиент выставляет пакет за дверь, курьер забирает его в выбранное временное окно и выбрасывает в контейнер. Каждый шаг подтверждается фотоотчётом.

Три приложения на одном сервере:

| Приложение | Адрес | Для кого | Демо-вход |
|---|---|---|---|
| Клиентское | `/client/` | жители (mobile-first) | `+70000000002` / `client` |
| Курьерское | `/courier/` | курьеры (mobile-first) | `+70000000001` / `courier` |
| Админ-панель | `/admin/` | диспетчер / админ | `+70000000000` / `admin` |

Есть второй курьер из «Северного» района: `+70000000003` / `courier`.

## Запуск

Нужен только **Node.js ≥ 22.13**. Внешних зависимостей нет: БД — встроенный `node:sqlite`, фронтенд — чистый JS без сборки.

```bash
cd trash-pickup/server
npm start          # http://localhost:3000
npm test           # API-тесты (полный цикл заказа, права, статусы)
npm run reset      # удалить БД и фото (при следующем старте создадутся демо-данные)
```

Переменные окружения: `PORT` (3000), `DB_FILE` (`server/data/app.db`), `UPLOADS_DIR` (`server/uploads`), `TZ` (часовой пояс для слотов, например `Europe/Moscow`).

## Что умеет

**Клиент:** регистрация по телефону, адреса (район, подъезд, этаж, домофон, где оставит пакет), заказ (тариф, число пакетов, дата и окно, комментарий, расчёт цены), статусы в реальном времени, фотоотчёт и история, отмена до выезда курьера, оценка и отзыв.

**Курьер:** смены (начать/завершить), свободные заказы своего района, взять/отказаться, «Выехал» → «Забрал» (обязательно фото у двери) → «Выбросил» (обязательно фото у контейнера), «Проблема» (причина и фото), карта и звонок клиенту, заработок за день/неделю/месяц и рейтинг.

**Админ:** дашборд дня (без курьера, в работе, проблемы, просрочка, кто на смене, выручка), заказы с фильтрами и поиском, карточка заказа (назначение и переназначение курьера, ручная смена статуса, отмена, фото, история), курьеры (добавить, район, блокировка, сброс пароля), клиенты, тарифы (цена клиенту и выплата курьеру), районы, отчёты за период (выручка, выплаты, маржа, средний чек, рейтинг, время выполнения; разрезы по курьерам, районам, тарифам и дням) и выгрузка заказов в CSV для Excel.

Архитектура, модель данных, статусы, API и план развития: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
