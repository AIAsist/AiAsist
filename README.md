# ИИ-Ассистент (AiAsist)

Нативное Android-приложение — **голосовой помощник для телефона** на базе **Claude API**
(Anthropic). Вы говорите, что нужно сделать, — Claude понимает запрос, при необходимости
вызывает инструменты устройства (звонок, SMS, будильник, навигация, фонарик и др.), а ответ
озвучивается вслух.

## Как это работает

```
Голос → распознавание речи (Android SpeechRecognizer)
      → Claude Messages API (tool-use: модель сама решает, какой инструмент вызвать)
      → выполнение действия на телефоне (Android Intents / системные сервисы)
      → ответ модели → синтез речи (Android TextToSpeech)
```

«Мозг» ассистента — Claude с **tool use**: модель получает текст запроса и список доступных
инструментов телефона, сама выбирает нужный, приложение его выполняет и возвращает результат,
после чего Claude формирует короткий голосовой ответ. Цикл повторяется, пока задача не решена.

## Возможности (инструменты)

| Инструмент | Что делает |
|---|---|
| `open_app` | Открыть приложение по названию |
| `phone_call` | Позвонить контакту или на номер |
| `send_sms` | Подготовить SMS (отправку подтверждает пользователь) |
| `set_alarm` | Поставить будильник |
| `set_timer` | Запустить таймер |
| `create_calendar_event` | Создать событие в календаре |
| `open_url` | Открыть сайт |
| `web_search` | Поиск в интернете |
| `navigate` | Построить маршрут на картах |
| `set_media_volume` | Громкость мультимедиа |
| `toggle_flashlight` | Фонарик вкл/выкл |
| `get_device_status` / `get_datetime` | Время, дата, заряд батареи |
| `open_settings` | Открыть раздел настроек (Wi-Fi, Bluetooth и т.д.) |
| `open_camera` | Камера (фото/видео) |
| `play_music` | Включить музыку |

На обычные вопросы (факты, перевод, советы) ассистент отвечает сам, без инструментов.

## Технологии

- **Kotlin** + **Jetpack Compose** (Material 3)
- **OkHttp** — запросы к Anthropic Messages API (`POST /v1/messages`)
- **EncryptedSharedPreferences** — зашифрованное хранение ключа API
- Android **SpeechRecognizer** и **TextToSpeech** — голос
- minSdk 26 (Android 8.0), targetSdk 35

## Сборка

Для сборки нужен Android SDK (Android Studio). В этом репозитории уже есть Gradle wrapper.

1. Откройте проект в **Android Studio** (Giraffe/Koala или новее) — он сам подтянет зависимости.
   Либо из командной строки:
   ```bash
   ./gradlew assembleDebug
   ```
   Готовый APK появится в `app/build/outputs/apk/debug/`.
2. Установите на телефон и запустите.

> Приложение собирается в Android Studio/Gradle с установленным Android SDK. В облачной среде
> без Android SDK сборка APK недоступна — проект рассчитан на локальную сборку.

## Настройка

1. Получите ключ API в консоли Anthropic: https://console.anthropic.com/
2. Запустите приложение → иконка **⚙️ Настройки** → вставьте ключ (`sk-ant-…`) → **Сохранить**.
3. Выберите модель:
   - `claude-opus-5-5` — самая умная (по умолчанию);
   - `claude-sonnet-5-5` — баланс скорости и качества;
   - `claude-haiku-4-5` — самая быстрая (рекомендуется для голоса при приоритете скорости).

Ключ хранится **только на устройстве** в зашифрованном виде и уходит исключительно на
`api.anthropic.com`.

## Разрешения

При первом запуске приложение запрашивает: микрофон, звонки, SMS, контакты, уведомления.
Остальные действия (будильник, календарь, навигация, фонарик, настройки) работают через
системные приложения и отдельных разрешений не требуют. Если разрешение на звонки не выдано,
ассистент откроет набор номера вместо автоматического вызова.

## Безопасность

Ключ API встроен в клиентское приложение (хранится зашифрованным на устройстве). Это приемлемо
для личного помощника, но ключ не следует распространять вместе с собранным APK. Для публичного
распространения вынесите вызовы Claude на собственный backend-прокси.

## Структура проекта

```
├── MainActivity.kt            # навигация, запрос разрешений
├── AiAsistApp.kt
├── ai/
│   ├── ClaudeClient.kt        # Messages API + цикл tool-use (с сохранением thinking-блоков)

│   └── DeviceActions.kt       # выполнение действий через Intents/сервисы

│   ├── SpeechRecognizerManager.kt
│   └── TextToSpeechManager.kt

│   └── SettingsRepository.kt  # зашифрованное хранение ключа и модели
└── ui/
    ├── AssistantViewModel.kt  # оркестрация голос → Claude → действие → речь
    ├── AssistantScreen.kt     # главный экран (микрофон, диалог)
    ├── SettingsScreen.kt      # ключ API и выбор модели
    └── theme/Theme.kt
```
